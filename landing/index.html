Why Tengga

Built for Precision, Engineered for Speed

Everything you need to inspect, stage, and discard Git changes with precision—and nothing you don't.

✂️

Hunk-by-Hunk Control

Stage clean hunks and leave debug logs unstaged. No more navigating tedious terminal menus in git add -p.

⚡

Instant File Watcher

Equipped with a debounced native filesystem watcher. Press Cmd+S in VS Code, Zed, or Neovim and Tengga updates in milliseconds.

🌿

First-Class Worktrees

Switch effortlessly between multiple git worktrees in convenient tabs without juggling multiple app windows.

🦀

Tauri v2 + Rust Core

Zero Chromium overhead. Native OS webview and Rust backend ensure sub-second cold starts and negligible memory usage.

🔀

Branch & MR Comparison

Compare your working branch against main or merge request targets before pushing upstream.

🎨

Dark, Light & Glass Themes

Crafted with modern typography (Plus Jakarta Sans & JetBrains Mono) and native macOS vibrancy for long, fatigue-free review sessions.
